# FinTechDemo 測試規格書

> 對齊 EngineeringOS `knowledge/testing.md`、TradingCRUD Fixture 模式。  
> Fixture：`docs/test-data/{auth,order,risk,account}/` · 載入器：`DemoTestFixtures`

## 分層

| 層 | 位置 | 入口 |
|----|------|------|
| Unit | 各模組 `src/test` | `gradlew test` |
| Integration | `@Tag("integration")` MockMvc | 同上（`check`） |
| Performance | `loadtest/` | `.\scripts\run-loadtest.ps1` |
