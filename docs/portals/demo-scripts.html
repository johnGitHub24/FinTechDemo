命名原則（看檔名就知道類）

前綴類別做什麼
platform-*設定／函式庫埠、K8s、kubeconfig
ensure-*／開啟Demo.cmd本機啟動拉起 bootRun／Vite…
start-k8s-*／k8s-*／check-k8sK8s部署／walkthrough／YAML
doctor-*／verify-*／smoke-*／check-*診斷／驗證探針、閘門
run-*壓測Locust
start-demo*／start-guide相容舊名薄轉發，勿再擴功能

0. 設定／函式庫 必須

platform-run.properties

用途：Demo 埠號、K8s 叢集名、ENABLE_K8S、DOCKER_BUILD_PLATFORM 的單一真相。

怎麼用：用編輯器改數值即可；腳本經 platform-env.ps1 讀取。改埠只改這裡。

platform-env.ps1

用途：函式庫。其他腳本 . platform-env.ps1 載入上面 properties。

怎麼用：不要單獨當一鍵執行；被 ensure／k8s／doctor 引用。

1. 本機啟動 必須

ensure-demo-links.ps1 權威實作

用途：LOOP 拉起 Order／Risk／Vite／Gateway／Account／Job／Docs…；已 UP 則保留。

誰呼叫：開啟Demo.cmd、DemoStackBootstrap -FromOrder、doctor -Fix。

.\demo\ensure-demo-links.ps1
.\demo\ensure-demo-links.ps1 -ForceRestart
.\demo\ensure-demo-links.ps1 -SkipDocker -SkipLocust

常用參數：-ForceRestart 重啟 Order／Account；-FromOrder 由 Java 背景觸發；-SkipDocker／-SkipLocust 省 RAM。

start-demo-ready.ps1 相容

用途：舊一鍵就緒 → 轉發 ensure。請改用 開啟Demo.cmd。

.\demo\start-demo-ready.ps1 -ForceClean

start-demo.ps1 相容

用途：舊最小啟動 → 轉發 ensure，或 -Minimal 只印指引。

.\demo\start-demo.ps1 -Minimal

start-guide.ps1 相容

用途：印出四個入口說明（本機／K8s／doctor／pipeline）。

.\demo\start-guide.ps1

2. K8s 與本機擇一

start-k8s-demo.ps1 權威

用途：kind 叢集 → build／load 映像 → apply → 等 Pod Ready。

.\開啟K8sDemo.cmd
.\demo\start-k8s-demo.ps1 -RecreateCluster

需 Docker Desktop Ready。前端需另 port-forward + Vite。

k8s-walkthrough.ps1

用途：檢查 Desktop Images ↔ kind 節點 ↔ Pods 三層是否對齊。

.\demo\k8s-walkthrough.ps1
.\demo\k8s-walkthrough.ps1 -Fix

check-k8s.ps1

用途：只跑 kubectl kustomize 驗 YAML，不連叢集、不建 kind。

.\demo\check-k8s.ps1

3. 診斷／驗證 必須

doctor-demo.ps1

用途：看哪些埠 DOWN、給修復建議；-Fix 呼叫 ensure。

.\demo\doctor-demo.ps1
.\demo\doctor-demo.ps1 -Fix -OpenBrowser
.\demo\doctor-demo.ps1 -FrontendOnly

verify-demo-shortcuts.ps1

用途：只探測 Demo 快捷 URL（Vite／Swagger／Grafana…），不啟動服務。

.\demo\verify-demo-shortcuts.ps1

有 FAIL → 先 開啟Demo.cmd 或 doctor -Fix。

verify-pipeline.ps1

用途：推版閘門：gradlew check + compose config + k8s overlay。

.\demo\verify-pipeline.ps1
.\demo\verify-pipeline.ps1 -Up -Smoke

smoke-distributed.ps1

用途：Compose 起 Kafka／Redis 後，探測並可手測 login→下單→execute。

.\demo\smoke-distributed.ps1
.\demo\smoke-distributed.ps1 -SkipCompose

check-docs-links.ps1

用途：掃描 docs HTML 本地連結是否壞掉（不含 javadoc）。

.\demo\check-docs-links.ps1

4. 壓測／可選工具 按需

run-loadtest.ps1

用途：Locust 壓測（baseline→Order :8081；fullflow→Gateway :8080）。

.\demo\run-loadtest.ps1
.\demo\run-loadtest.ps1 -Scenario fullflow -HostUrl http://localhost:8080
.\demo\run-loadtest.ps1 -WebUi

start-monitoring-local.ps1

用途：無 Docker 時本機起 Prometheus :9090／Grafana :3000。

.\demo\start-monitoring-local.ps1

export-blueprint-diagrams.ps1

用途：把藍圖 Mermaid 匯出成 PNG／SVG（簡報用）。

.\demo\export-blueprint-diagrams.ps1

為什麼不能再砍成一支？

組合原因
ensure + doctor + verify-pipeline啟動／修／閘門三種職責
start-k8s + walkthrough + check-k8s部署／三層檢查／純 YAML 三層級
其餘小腳本場景不同、體積小、按需用
