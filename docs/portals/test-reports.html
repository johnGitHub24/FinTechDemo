FinTechDemo — 測試報告入口

Gradle HTML 報表（跑過 check 後才有檔）。單元與整合目前同屬 test task，報表路徑相同；下方依類別名稱分區導覽。

Docs 首頁 測試與 CI（MD） testing HTML Javadoc

產生報表

先跑驗證，再開本頁各模組連結（需 serve-docs :5500，或直接開本機檔案）。

.\scripts\check.ps1
# 或 .\gradlew.bat check

報表路徑：{module}/build/reports/tests/test/index.html。若 404，代表尚未跑過該模組測試。

單元測試報告

偏純邏輯／Mock：Service、Filter、Jwt、Topology 等（類名多為 *Test，不含 Integration）。點模組開 Gradle HTML，再於報表內點對應 class。

例：RiskServiceTest、TradingServiceTest、AuthServiceTest、JwtTokenProviderTest、RateLimitWebFilterTest、TopologyServiceInferStageTest、AccountLedgerServiceTest、StaleOrderServiceTest

整合測試報告

偏 Spring Boot／API／DB：類名含 Integration 或 *ApplicationTest。同一個模組 HTML 報表裡可看到綠燈／失敗細節。

例：OrderApiIntegrationTest、AuthIntegrationTest、TradingFlowIntegrationTest、RiskApiIntegrationTest、AccountApiIntegrationTest、各服務 *ApplicationTest

Demo 快捷面板 → 學習文件 →「單元測試／整合測試」會連到本頁錨點。Javadoc 另見 docs/javadoc/（.\gradlew.bat aggregateJavadoc）。
