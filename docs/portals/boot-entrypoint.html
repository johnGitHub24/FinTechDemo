FinTechDemo — 從「執行」到 Entry Point

設定檔載入 · classpath · SpringApplication.run · 進入 main／就緒。以 OrderServiceApplication（:8081）為主路徑說明。

啟動與 Demo 運作流程 CodeGraphic 規格書 architecture

① 你怎麼按「執行」——三種入口殊途同歸

  • 最短 Demo：IntelliJ 跑 OrderServiceApplication（模組 order-service）。
  • 或終端：.\gradlew.bat :order-service:bootRun。
  • Docker：根目錄 Dockerfile 的 ENTRYPOINT java -jar app.jar（同樣進 main）。

日誌關鍵字：出現 Starting OrderServiceApplication 代表已進入 Spring Boot 啟動；Started OrderServiceApplication 代表就緒。

② JVM 載入 → 進入 main（真正的 Entry Point）

  • public static void main 是 JVM 約定的程式入口；Spring Boot 應用也不例外。
  • @SpringBootApplication＝組態＋元件掃描＋自動組態的捷徑注解（此時尚未掃描，只是類別上的標記）。
  • SpringApplication.run(...) 才開始建立 ApplicationContext。
sequenceDiagram participant JVM as JVM participant CL as ClassLoader participant App as OrderServiceApplication participant SA as SpringApplication JVM->>CL: 載入主類 OrderServiceApplication CL-->>JVM: 解析注解中繼資料完成 JVM->>App: 呼叫 main(args)【Entry Point】 App->>SA: SpringApplication.run(App.class, args) SA->>SA: 建立實例並推斷 SERVLET SA->>SA: 準備 Environment / listeners

ClassLoader 會讀 .class 並解析 @SpringBootApplication／@EnableFeignClients 中繼資料；main 是你寫的第一行業務啟動碼，其餘 Bean 要等 refresh()。

flowchart LR A["main()"] --> B["new SpringApplication(primarySources)"] B --> C["推斷 WebApplicationType.SERVLET"] C --> D["建立 ApplicationContext
AnnotationConfigServletWebServer..."] D --> E["refresh() 載入 Bean"]

對照原始碼：OrderServiceApplication.java 只有 main → SpringApplication.run。其餘 Controller／Service 都是 refresh 階段才變成 Bean。

③ 設定檔／環境變數怎麼載入（在 refresh 早期）

  • Spring Boot 從 classpath 根讀 application.yml（以及 application-{profile}.yml）。
  • 環境變數／系統屬性／命令列 --key=value 會覆寫 yml（鬆散綁定：FINTECH_KAFKA_ENABLED ↔ fintech.kafka.enabled）。
  • Demo 全棧：compose 設 SPRING_PROFILES_ACTIVE=demo → 再載入 application-demo.yml。

若埠被占用（例如 8081 被其他程式佔用），失敗點在「WebServer 啟動」而不是 main 進不去——設定檔其實已載入。

④ Spring 建置上下文：掃描 → 自動組態 → Bean

  • @SpringBootApplication 從 com.fintech.demo.order 套件往下掃描 @Component／@Service／@RestController 等。
  • @EnableFeignClients 註冊 Feign 介面（呼叫 risk／account）。
  • 依 classpath 自動組態：Web／JPA／Security／Kafka／Actuator…（可被 yml 條件關閉）。

⑤ 就緒：ApplicationReadyEvent → 可接請求

  • Tomcat 開始聽埠後，發布 ApplicationReadyEvent。
  • StartupInfoLogger 監聽此事件，印出各服務 URL（受 startup.info.enabled 控制）。
  • 之後 HTTP 請求：Filter（JWT）→ Controller → Service → Repository／Feign。

⑥ Gateway 啟動變體（record Properties）

  • 入口類：GatewayApplication（:8080）。
  • application.yml 的 fintech.services.*-url → 綁定 ServiceUrlsProperties record。
  • GatewayRouteConfig 注入 Properties，用 urls.orderUrl()／accountUrl() 建路由（非 getXxx）。
