## 2. 最短可成交 Demo（人工）

> **Loop Engineering（預設）**：只起 `OrderServiceApplication` 即可；
> `DemoStackBootstrap` 會背景跑 `ensure-demo-links.ps1` 補齊 Risk／Vite／Gateway…  
> 詳見 [啟動與 Demo 運作流程 §2](portals/demo-flow.html#s2)。

| # | 步驟 | 預期 |
|---|------|------|
| B1 | 起 `OrderServiceApplication` :8081 | health／Swagger 可開；Console 有 `【LOOP】` |
| B2 | 等 1～3 分鐘（或看 `logs/ensure-from-order.*.log`） | Risk／Vite 變 UP；可選 Gateway／Account／Job／Docs |
| B3 | http://localhost:5173/login | 登入頁可開 |
| B4 | `trader1` / `password` 登入 | 進交易前台 |
| B5 | 下單 → PENDING | 訂單出現 |
| B6 | 點「成交」 | Risk Feign 通過 → `ACCEPTED`；關 Risk 再開成交應失敗可見 |
| B7 | `/blueprint` | 技術棧表／Mermaid 圖可渲染（可不登入） |
| B8 | PROCESS FLOW（Trade 右側） | 有 demoTrace／拓撲燈（Peers 需起來才綠） |
| B9 | 登出改 `admin` / `password` → `/portal` | 餘額 100000、持倉空白（本人）；歷史標「全站」、AAPL 成交列擁有者 `trader1` |

一鍵手動：`開啟Demo.cmd` 或 `.\scripts\doctor-demo.ps1 -Fix`  
關閉自動補齊（測試）：`fintech.startup.ensure-stack=false`
