ER Model（全部 tables）

erDiagram USERS ||--|| ACCOUNTS : owns USERS ||--o{ ORDERS : places USERS ||--o{ POSITIONS : holds USERS ||--o{ AUDIT_LOG : audits USERS { bigint id PK varchar username UK varchar password_hash varchar role } ACCOUNTS { bigint id PK bigint user_id FK decimal cash_balance varchar currency } ORDERS { bigint id PK bigint user_id FK varchar client_order_id UK varchar symbol varchar side int quantity decimal price varchar status timestamp created_at timestamp updated_at } POSITIONS { bigint id PK bigint user_id FK varchar symbol int quantity decimal avg_price } AUDIT_LOG { bigint id PK varchar action varchar resource varchar detail varchar username timestamp created_at }

列舉語意（圖上省略 |，避免 Mermaid erDiagram 語法錯誤）：
role＝USER／ADMIN；side＝BUY／SELL；status＝PENDING／ACCEPTED／REJECTED／CANCELLED。
accounts.user_id、positions(user_id,symbol) 為 UNIQUE（見下方索引）。
