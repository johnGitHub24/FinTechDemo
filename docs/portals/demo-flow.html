2.2 ensure 腳本內部順序（KEEP／只補 DOWN）

flowchart TB subgraph ORDER_READY["Order 已就緒 :8081"] L["StartupInfoLogger 印燈號 UP/DOWN"] B["DemoStackBootstrap 背景執行緒"] end subgraph ENSURE["ensure-demo-links.ps1"] R["① Risk :8082"] A["② Account :8084"] O["③ Order :8081（已 UP→KEEP）"] G["④ Gateway :8080"] J["⑤ Job :8083"] V["⑥ Vite :5173"] D["⑦ Docs :5500"] M["⑧ Grafana :3000 / Prom :9090"] Lct["⑨ Locust :8089"] end L --> B --> R --> A --> O --> G --> J --> V --> D --> M --> Lct Lct --> VFY["Verify probe 含觀測／壓測"]
  1. Risk 最先補：沒它就不能「成交」（Feign）。
  2. Account：帳務／Redis 敘事（S3）。
  3. Order：若已由 IntelliJ 啟動 → 探測 UP 直接 KEEP，不重複起。
  4. Gateway：統一入口（S3）。
  5. Job：逾時取消（不進 S 公式）。
  6. Vite：前端登入／藍圖。
  7. Docs：serve-docs :5500 學習 HTML。
  8. Grafana／Prometheus：Docker --profile monitoring。
  9. Locust：本機 Python Web UI :8089。

預設一併拉起 Grafana／Prometheus／Locust（對齊 Demo 快捷可點）。 省 RAM：設 fintech.startup.ensure-skip-docker=true／ensure-skip-locust=true， 或手動腳本加 -SkipDocker -SkipLocust。

3. 前後台操作劇本（Demo 現場）

  1. 用 trader1 登入 → 進入 /trade
  2. 選 symbol（如 MSFT）、數量 1、下單 → 列表出現 PENDING
  3. 點執行（若 UI 有）或用 Swagger POST /api/orders/{id}/execute
  4. 進 /portal：餘額減少、持倉／歷史更新
  5. 登出，用 admin 登入 → /portal：講「餘額是本人 100000、歷史是全站」；AAPL 列擁有者是 trader1。再進 /portal/audit
  6. （加分）未登入開瀏覽器隱私模式打 API → 401
sequenceDiagram actor U as 使用者 participant FE as Vue:5173 participant API as order:8081 U->>FE: 登入 FE->>API: POST /api/auth/login API-->>FE: JWT U->>FE: /trade 下單 FE->>API: POST /api/orders + Bearer U->>FE: /portal 查餘額歷史 FE->>API: GET /api/accounts/me 、 /api/orders

4. API／Swagger 驗證

  1. 開 docs/swagger.html 或 Runtime Swagger
  2. POST /api/auth/login → 複製 token
  3. 右上 Authorize：Bearer <token>
  4. 試 GET /api/orders、GET /api/accounts/me
# PowerShell 快速煙霧
$login = Invoke-RestMethod http://localhost:8081/api/auth/login -Method POST `
  -ContentType application/json -Body '{"username":"trader1","password":"password"}'
$h = @{ Authorization = "Bearer $($login.token)" }
Invoke-RestMethod http://localhost:8081/api/accounts/me -Headers $h
Invoke-RestMethod "http://localhost:8081/api/orders?page=0&size=5" -Headers $h
