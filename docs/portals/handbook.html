入門

第 1 章　這專案在幹嘛

前後台配合的迷你券商 Demo：登入後前台下單、後台查歷史／餘額；再展示 Gateway／微服務／Kafka／Redis。

你要能講的三句

  1. 產品：JWT＋RBAC，USER／ADMIN 權限不同
  2. 架構：Vue → Gateway → order／risk／account
  3. 事件：order-events → 風控執行 → trade-events → account＋清 Redis

第 5 章　分散式怎麼講

  • 微服務：三個業務服務拆邊界（不一定要 Eureka）
  • 同步：Feign 叫 risk
  • 非同步：Kafka topic 當 event bus
  • 快取：account 讀路徑 Redis，入帳後 evict
  • Eureka：可口述改 lb://，Demo 用固定 URL 保證可跑
