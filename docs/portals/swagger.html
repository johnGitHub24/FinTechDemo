API 分組

  • Auth：POST /api/auth/login
  • Orders：CRUD／execute／cancel
  • Account：/api/accounts/me、/api/positions
  • Portal：audit（ADMIN）、symbols
  • Risk：內部 Feign /api/risk/check

認證與 Demo 流程

  • 帳號 trader1／admin，密碼 password
  • login → 複製 token → Authorize → Bearer <token>
  • 前台：下單／取消 · 後台：餘額／持倉／歷史
  • ADMIN 才能看 audit

本頁預設載入 /docs/openapi.yaml（離線可讀契約）。真正打 API 請先 bootRun，或開 Runtime Swagger（:8081）。

怎麼用（正常流程）： ① 下方綠色 Authorize 貼 JWT（先用 Auth → login）→ ② 點 Auth／Orders／Account… 展開 → ③ 點某支 API → Try it out。
Servers 只是選「請求打到哪一台」（8081 order／8084 account／8080 Gateway）， 不會換頁；換完後 Try it out 才打到對應埠。
